# Australian comedy poster replacements

Five additions replace repeated links in the Goon And Glory scene: The Dish,
Angry Boys, Kenny, Crackerjack, and Swift and Shift Couriers. Existing unique
posters remain. `sources.json` records source pages, original URLs, hashes,
pixel sizes, scene component IDs and the original links.

Each PNG exactly matches the previous image's pixel dimensions (405x720 or
454x650). The artwork is fitted to the measured display surface, with pixels
precompensated for the existing mesh/UV aspect and a small matte border to keep
titles and credits visible. Native PNG proportions may look compressed; the
unchanged poster mesh expands them to the intended appearance. Meshes,
transforms, materials and UVs are not modified.

These are static, direct PNG URLs for the existing image downloader. They do
not change the headband game's imagery or cache. Promotional artwork remains
the property of its owners; this index does not grant a reuse licence.
